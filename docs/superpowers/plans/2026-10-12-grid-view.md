# Grid View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A desktop-only `/grid` route in the cockpit shell: fleet sidebar on the left, a tab strip and 1–6 resizable terminal panes on the right, each pane an iframe of the existing `/term/` document, with keyboard chords that work from inside a terminal, parking of hidden tabs, and a layout that survives reload.

**Architecture:** Pure state and chord logic live in `web/grid/` (Node-testable, no DOM); the Preact view `web/views/grid.mjs` renders from one signal and mounts each pane's iframe exactly once; the terminal page gains a small forwarder that posts chords to its parent when framed. Server changes are route plumbing only (shell route regex, nav entry, service-worker allowlist).

**Tech Stack:** Preact 11 + `@preact/signals` (already in the shell), esbuild build (`node build.mjs`, `dist/` committed), Playwright probes under `docs/qa/probes/`, Node check scripts under `scripts/` run by `scripts/preflight.sh`.

**Spec:** `docs/superpowers/specs/2026-10-11-grid-view-design.md`

## Global Constraints

- Branch `feat/grid-view`, PR to `main`; deploy from the branch with `scripts/deploy-dashboard.sh`, verify live, then merge (standing rule).
- `node build.mjs` after every change under `web/`; `dist/` is committed with the source (K-25). `git diff --exit-code -- dist/` must be clean after a rebuild.
- Budgets (gzip-9, `node scripts/budget.mjs --all`): view route closure `grid` ≤ 15 KB, `tokens.css` ≤ 12 KB (not touched), `term` closure ≤ 130 KB, server JS ≤ 140 KB. No HTML/CSS strings in `infra/dashboard/{lite.mjs,routes,sse.mjs,static.mjs}` (K-27); `legacy.mjs` is where nav markup lives.
- `PREFLIGHT_NO_LOCAL=1 ./scripts/preflight.sh` must pass: every new file is listed in `scripts/manifest.txt` (sorted, path per line); no IPv4-looking literals in any file.
- Shell CSP: `style-src 'self' 'nonce-…'` — no inline `<style>`; the view's CSS goes in through `document.adoptedStyleSheets` (CSSOM, not governed by CSP). `frame-src 'self'` is already set for the shell document.
- Helper modules go in `web/grid/`, never in `web/views/` (every file there becomes a build entry).
- Dev instances: `MOWS_TEST_HOOKS=1 node infra/dashboard/lite.mjs --port 3105 --host 127.0.0.1 --ui=next`; check `ss -ltnp | grep :31` first; kill by PID, never `pkill -f`.
- Never attach the probe or a dev instance to a real session: probes stub `/term/**`; the only live test is the manual gate on mows.me, on sessions you own.
- Commit trailer on every commit: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01K566DhVHb9QoT1sUDza2jZ`.
- Caps from the spec: 6 panes per tab, 9 tabs, sidebar 180–480 px, column ≥ 160 px, parking after 10 min hidden.

## Deviations from the spec (small, recorded here)

- No `desk` class and no tokens.css rule: the `Grid` link goes into `.pnav` only. `.pnav` sits in `.navdup`, which tokens.css already hides below 701 px, and the phone bar `.tabs` is left alone, so the phone never sees the link.
- The `grid-key` message carries the decoded action (`{ t: 'grid-key', key: 'tab:3' }`) rather than the raw key, so the shell and the forwarder share one decoder (`web/grid/keys.mjs`).

## Review Focus

1. A stored layout naming a session that is gone (box rebooted overnight): the view must mount with that pane dropped and say so, never a blank tab or an iframe attaching to nothing. → Task 1 (`load` drops it) and Task 4 probe `persist`.
2. A session that ends while its pane is on screen, then a new session with the same tmux name appears: the pane shows `ended`, and clicking it again must not open a second iframe for the same name. → Task 4 (`ended`), Task 1 (`find` before `openTab`).
3. Dragging a column handle past the pointer leaving the window, or releasing over an iframe: fractions must stay normalised and ≥ 160 px each, and the drag must end. → Task 5.
4. Chords on a Mac with `Mod = mac` while a text input in the sidebar has focus: ⌘⇧S must still reach the filter, ⌘⇧← must not move panes while the caret is in the filter. → Task 6.
5. Ten minutes hidden, then the user returns and the active tab's sessions are still live: parking must not have closed the sockets of the tab they are looking at, and the parked tabs must come back on click without a reload. → Task 7.

```js
// state.mjs — the grid view's layout state, pure: every function returns a new state. Persisted as localStorage['grid.v1'] by the view
// (spec §6). Pane entries are tmux session names; tab ids are 't<n>' from the counter `n`. `notice` is a one-line message for the strip
// (a refused cap, dropped sessions) and is never stored.
export const KEY = 'grid.v1';
export const CAPS = { panes: 6, tabs: 9, sidebar: [180, 480], minCol: 160, park: 600000 };
export const colsFor = n => (n <= 3 ? n : n === 4 ? 2 : 3);
const even = k => Array.from({ length: k }, () => 1 / k);
const norm = cols => { const t = cols.reduce((a, b) => a + b, 0) || 1; return cols.map(c => c / t); };
const fit = tab => { const k = colsFor(tab.panes.length); return { ...tab, cols: tab.cols.length === k ? tab.cols : even(k), focus: Math.min(tab.focus, tab.panes.length - 1), zoom: tab.zoom != null && tab.zoom < tab.panes.length ? tab.zoom : null }; };
const clamp = (v, lo, hi) => Math.min(hi, Math.max(lo, v));
const tabAt = (s, id) => s.tabs.findIndex(t => t.id === id);
const upd = (s, id, f) => ({ ...s, notice: '', tabs: s.tabs.map(t => (t.id === id ? fit(f(t)) : t)) });

export const empty = mod => ({ sidebar: 260, grouped: true, mod, active: '', n: 0, notice: '', tabs: [] });

export function find(s, name) {
  for (const t of s.tabs) { const i = t.panes.indexOf(name); if (i >= 0) return { tab: t.id, i }; }
  return null;
}
export function openTab(s, name) {
  const at = find(s, name);
  if (at) return upd({ ...s, active: at.tab }, at.tab, t => ({ ...t, focus: at.i }));
  if (s.tabs.length >= CAPS.tabs) return { ...s, notice: `at most ${CAPS.tabs} tabs` };
  const id = 't' + (s.n + 1);
  return { ...s, n: s.n + 1, active: id, notice: '', tabs: [...s.tabs, { id, panes: [name], cols: [1], focus: 0, zoom: null }] };
}
export function split(s, name) {
  if (!s.active) return openTab(s, name);
  const at = find(s, name);
  if (at && at.tab === s.active) return upd(s, at.tab, t => ({ ...t, focus: at.i }));
  if (at) return openTab(s, name); // open in another tab: go there, never a second socket
  const tab = s.tabs[tabAt(s, s.active)];
  if (tab.panes.length >= CAPS.panes) return { ...s, notice: `at most ${CAPS.panes} panes in a tab` };
  return upd(s, s.active, t => ({ ...t, panes: [...t.panes, name], cols: [], focus: t.panes.length, zoom: null }));
}
export function closePane(s, id, i) {
  const k = tabAt(s, id); if (k < 0) return s;
  const t = s.tabs[k];
  if (t.panes.length <= 1) {
    const tabs = s.tabs.filter(x => x.id !== id);
    const active = s.active === id ? (tabs[Math.min(k, tabs.length - 1)]?.id || '') : s.active;
    return { ...s, tabs, active, notice: '' };
  }
  return upd(s, id, x => ({ ...x, panes: x.panes.filter((_, j) => j !== i), cols: [], focus: i < x.focus ? x.focus - 1 : x.focus, zoom: null }));
}
export const focusPane = (s, id, i) => upd({ ...s, active: id }, id, t => ({ ...t, focus: clamp(i, 0, t.panes.length - 1) }));
export const setActive = (s, id) => (tabAt(s, id) < 0 ? s : { ...s, active: id, notice: '' });
export function stepTab(s, d) { const k = tabAt(s, s.active); if (k < 0 || s.tabs.length < 2) return s; return setActive(s, s.tabs[(k + d + s.tabs.length) % s.tabs.length].id); }
export function stepPane(s, d) { const k = tabAt(s, s.active); if (k < 0) return s; const t = s.tabs[k]; return focusPane(s, t.id, (t.focus + d + t.panes.length) % t.panes.length); }
export function toggleZoom(s) { const k = tabAt(s, s.active); if (k < 0) return s; return upd(s, s.active, t => ({ ...t, zoom: t.zoom == null ? t.focus : null })); }
export function moveTab(s, from, to) { const tabs = [...s.tabs]; const [t] = tabs.splice(from, 1); tabs.splice(to, 0, t); return { ...s, tabs }; }
export const setCols = (s, id, cols) => upd(s, id, t => ({ ...t, cols: norm(cols) }));
export const setSidebar = (s, px) => ({ ...s, sidebar: clamp(Math.round(px), CAPS.sidebar[0], CAPS.sidebar[1]) });
export const setMod = (s, mod) => ({ ...s, mod });
export const setGrouped = (s, grouped) => ({ ...s, grouped });

export function load(storage, live, mod) {
  let raw = null;
  try { raw = JSON.parse(storage.getItem(KEY) || 'null'); } catch { raw = null; }
  if (!raw || typeof raw !== 'object' || !Array.isArray(raw.tabs)) return { state: empty(mod), dropped: [] };
  const dropped = [];
  const tabs = raw.tabs.map(t => {
    const panes = (Array.isArray(t.panes) ? t.panes : []).filter(n => { const ok = typeof n === 'string' && live.has(n); if (!ok && typeof n === 'string') dropped.push(n); return ok; });
    return fit({ id: String(t.id || ''), panes, cols: Array.isArray(t.cols) ? t.cols.map(Number) : [], focus: Number(t.focus) || 0, zoom: Number.isInteger(t.zoom) ? t.zoom : null });
  }).filter(t => t.panes.length && /^t\d+$/.test(t.id));
  const n = Math.max(Number(raw.n) || 0, ...tabs.map(t => +t.id.slice(1)));
  const active = tabs.some(t => t.id === raw.active) ? raw.active : (tabs[0]?.id || '');
  const state = { sidebar: clamp(Number(raw.sidebar) || 260, CAPS.sidebar[0], CAPS.sidebar[1]), grouped: raw.grouped !== false, mod: ['mac', 'win', 'alt'].includes(raw.mod) ? raw.mod : mod, active, n, notice: '', tabs };
  return { state, dropped };
}
export function save(storage, s) {
  const { notice, ...rest } = s;
  try { storage.setItem(KEY, JSON.stringify(rest)); } catch { /* storage full or blocked: the layout is still on screen */ }
}
```

```js
// keys.mjs — the grid chords (spec §5), one decoder for the shell and for the terminal page's forwarder. `code`, not `key`: with Shift held
// `key` is '!' for the 1 key on a US layout. Close is X, never W: ⌘⇧W / Ctrl⇧W close the browser window and cannot be intercepted.
export const MODS = { mac: '⌘⇧', win: 'Ctrl⇧', alt: 'Alt' };
export const detectMod = (platform = navigator.platform) => (/^Mac|^iPad/.test(platform) ? 'mac' : 'win');
const held = (e, mod) => (mod === 'mac' ? e.metaKey && e.shiftKey && !e.ctrlKey && !e.altKey
  : mod === 'win' ? e.ctrlKey && e.shiftKey && !e.metaKey && !e.altKey
  : e.altKey && !e.ctrlKey && !e.metaKey && !e.shiftKey);
const CODES = { ArrowLeft: 'pane:-1', ArrowRight: 'pane:1', ArrowUp: 'tabrel:-1', ArrowDown: 'tabrel:1', KeyZ: 'zoom', KeyX: 'close', KeyS: 'filter' };
export function chordOf(e, mod) {
  if (!held(e, mod)) return null;
  const d = /^Digit([1-9])$/.exec(e.code);
  return d ? 'tab:' + d[1] : CODES[e.code] || null;
}
```
